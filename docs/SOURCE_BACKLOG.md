## 建议顺序

1. `people-daily`：补人民日报公开评论和理论版规范表述。
2. `ndrc`：补宏观经济、现代化产业体系、区域协调和新质生产力。
3. `mee`：补绿色低碳、美丽中国、生态文明体制改革。
4. `mca`：补基层治理、养老、社会救助和社区建设。
5. `gmw-theory`：作为理论文章补充来源。

## 落地原则

- 每个来源先做 2-3 个稳定公开栏目，不做全站泛抓。
- 优先找官方列表页、JSON 数据源或 RSS；没有稳定列表时才用首页链接发现。
- 使用 `--profile politics-theory` 或自定义 `--keywords` 控制备考相关性。
- 商业站、登录页、验证码、付费墙不纳入自动采集。
- Playwright 只作为 JS 渲染或用户本人登录资源的兜底，不作为政策站默认采集方式。
- 新 adapter 必须补 fixture、真实 smoke test、Obsidian wrapper 和文档规则。
